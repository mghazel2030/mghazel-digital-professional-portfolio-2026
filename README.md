# Mohsen Ghazel — Modern Digital Professional Portfolio

Responsive static HTML/CSS/JavaScript portfolio regenerated on 17-Aug-2026.

## Design goals

- One consistent global visual system across all pages.
- Global navigation on every page.
- Automatically generated page-specific table of contents.
- Responsive layouts for desktop, tablet, and mobile.
- Card/grid presentation instead of fixed-width tables.
- Scan-first storytelling with optional technical depth.
- Work Experience uses Context → Mission → TL;DR Impact → Core Stack → Deep Dive.
- GitHub projects split into Computer Vision, NLP / RAG / LLM, and Software & Web Development pages.

## Run locally

Open `index.html` directly, or serve the folder with any static HTTP server, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Shared assets

- `css/styles.css` — global design system and responsive breakpoints
- `js/script.js` — global navigation, mobile navigation, page TOC, active TOC highlighting, back-to-top control
- `assets/images/` — portfolio images inherited from the supplied project

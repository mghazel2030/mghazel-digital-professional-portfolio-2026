Project 1

Interactive MNIST Streamlit Digit Classifier App

An interactive **Streamlit** application for handwritten digit recognition using a compact **TensorFlow/Keras Convolutional Neural Network (CNN)** trained on the MNIST dataset. The application allows a user to draw a digit from **0 to 9** in the browser, preprocesses the drawing into MNIST-compatible form, runs inference with a trained CNN, and displays the predicted class, confidence, class probabilities, processed image, normalized pixel matrix, and MNIST test-set confusion matrix.
